# STATE

- **Текущая цель:** зафиксировать горячую карту проекта и состояние знаний по entrypoints, основным потокам, VPN/subscription flows.
- **Что уже известно:** Android `MainActivity` и desktop `DesktopMain` запускают Compose UI; `DataStore`+`SagerDatabase` хранят настройки и профили; `SimpleMode`+`bg` управляют click-to-connect, auto-select и подписками.
- **Потенциально проблемные места:** зависимости auto-select/ProbeScheduler на актуальность pool; фоновое обновление подписок и встроенный каталог должны синхронизироваться с `DataStore` флагами.
- **Следующие шаги:** использовать карту/состояние для ориентировки при дальнейшем расследовании и уточнить детали flows по мере необходимости.
