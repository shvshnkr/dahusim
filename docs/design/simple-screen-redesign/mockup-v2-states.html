Провалнет — молча сбрасывается в «Отключено»новый тон FAILED: красное кольцо + ⚠ + причина + «нажмите, чтобы повторить»
  • FAILED — терминальное состояние провала (не «Отключено»): видно, что пошло не так и как повторить.
  • RECOVERING — переключение/переподключение/перепроверка: пульс-дуга (не спин), иконка ↻, счётчик «Попытка N из M».
  • Степ-трейл Сеть → Подписки → Сервер → VPN: текущий этап пульсирует, пройденные — зелёные, упавший — красный ✕.
  • Горизонтальная полоска скана убрана — прогресс целиком в кольце (точная дуга), числа «Проверка URL 12/42…» остаются строкой деталей.
  • Idle — серый (красный только у реального провала).
  • Сканирование/подключение/подключено — без изменений.

Горячие клавиши: Пробел — play/pause, → — +1 с, ← — −1 с.
