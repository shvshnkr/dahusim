# Редизайн простого экрана (SimpleHomeScreen) — концепт

Ветка: `redesign`. Скоуп: только Compose/UI простого экрана; логика connect-координатора и
статус-машина не меняются.

## 1. Проблемы текущего экрана

| Проблема | Причина |
|---|---|
| «Scanning servers 1/1…» висит внизу | `AutoServerSelector` публикует `publishScan(done, total)` (`Probe2kProgress.kt`), но после завершения prepare-сканирования никто не вызывает `clearScan()` — последняя строка «N/N» остаётся в статус-карточке навсегда |
| Три карточки (описание / статус / WL-рамка) — визуальный шум, статус не в фокусе | Макет «колонка карточек» от старого Material-подхода |
| Главное действие (Connect) — одна из трёх кнопок внизу экрана | Кнопка не доминирует, не видно состояния до тапа |
| Состояние передаётся текстом и цветом строки, без единого визуального якоря | Нет единого элемента-индикатора (кольцо/круг) |

## 2. Бенчмарк популярных VPN-клиентов (GitHub)

| Приложение | Паттерн | Что берём |
|---|---|---|
| **v2rayNG** (2dust) | список профилей + power-кнопка, статус текстом | — (устаревший, берём только идею «всё в одной кнопке») |
| **ПроБел / v2whitelist** | гигантская круглая кнопка «Старт» по центру, флаги-фильтр стран | Круглая центральная кнопка = единственный якорь экрана |
| **Hiddify** (hiddify) | M3, карточка подключения, скорость/трафик, usage-бар | Вторичная строка деталей под статусом, а не карточка |
| **NekoBox** (MatsuriDayo) | дашборд + большая power-кнопка, статус-строка | Кольцо-состояние вокруг кнопки |
| **Outline** (Jigsaw-Code) | круглая кнопка с кольцом статуса (серый→оранж→зелёный) | Кольцо-индикатор состояния + пульс при подключении |
| **Proton VPN / Mullvad** | один большой переключатель, статус словом + страна | Минимум текста, максимум — один жест |

**Вывод:** современный паттерн — *одна большая круглая кнопка-индикатор* по центру,
статус словом под ней, вторичная строка деталей, всё остальное — вторичные действия внизу.

## 3. Структура экрана (сверху вниз)

```
┌─────────────────────────────┐
│  daHusiM                ⚙   │  TopBar: имя + иконка входа в полный UI
│  [WL-режим]   chip-строка   │  тонкая chip (не красная рамка-карточка)
│                             │
│        ┌───────────┐        │
│        │  ⏻  ▶  ✓  │        │  КРУГЛАЯ КНОПКА 120–160dp (см. §4)
│        └───────────┘        │
│   Подключено                │  Headline статуса (headlineMedium)
│   Pool: 12 alive · 3 jail   │  Detail (bodySmall, onSurfaceVariant)
│                             │
│  ── показ при необходимости:│
│  [⚠ connection dropped…]    │  SimpleModeUncleanStopNotice (тонкий)
│  [Share logs]  [Full UI]    │  вторичные действия (TextButton)
└─────────────────────────────┘
```

- Фон: тон-состояние через мягкий вертикальный градиент (5–8% тона, не кричащий) или
  чистая surface; акцентное свечение (radial) под кнопкой в тон состояния.
- Контейнеры-карточки не используются вообще — статус живёт в кнопке и тексте.

## 4. Круглая кнопка-индикатор (SimplePowerButton)

Кнопка — `Box` 140dp, круг, внутри `Icon` состояния; вокруг — кольцо статуса.

| Состояние | Кольцо | Кнопка | Иконка | Анимация |
|---|---|---|---|---|
| STOPPED | нет (серый контур) | surface/error | ⏻ power | — |
| PREPARING | пульсирующая дуга индиго (#5C6BC0) | индиго 12% | sync | плавный pulse 1.4s |
| CONNECTING | вращающаяся дуга янтарь (#C58A00) | янтарь 12% | power | rotation 1s linear |
| CONNECTED | полное зелёное кольцо (#2E7D32) + мягкое свечение | зелёный 12% | ✓ check | спокойное дыхание (opacity 0.8→1) |

**Прогресс сканирования живёт в кольце:** во время PREPARING дуга = `checked/total`
(conic-gradient), под кнопкой detail «Scanning servers 3/42…» + счётчик. Это убирает
«1/1 висит»: дуга исчезает по завершении prepare (см. §6), строка не «залипает» — она
всегда привязана к живому прогрессу, а не к последнему опубликованному значению.

- Permission-pending: кнопка показывает spinner-дугу + detail «Allow VPN when prompted…».
- Unclean-stop: под кнопкой тонкая orange-строка (существующий notice, стилизованный).

## 5. Взаимодействие

- Тап по кнопке: тот же `SimpleModeConnectCoordinator.start(connectHost)` — поведение
  НЕ меняется (H11-логи, `SimpleModeVpnSessionMarker`, permission flow — как сейчас).
- Кнопка недоступна только при `Stopping` (текущая логика `enabled`).
- «Стоп» = тап по зелёной кнопке (иконка меняется на ⏻ с confirm-пульсом) — текущий флоу.
- Поддержка reduced motion: отключать pulse/rotation, оставить статичные цвета.

## 6. Фикс «Scanning 1/1 висит» (входит в редизайн)

1. `Probe2kProgress.clearScan()` вызывать при: prepare-пайплайн завершён (после последнего
   `publishScan` при выходе из select), `Connected`, `Stopped`/`Idle`.
2. В UI: кольцо-прогресс рисуется только пока `checked < total` И `status` не
   Connected/Stopped; таймаут скрытия 8с без обновления `checked` → строка гаснет.
3. Тест: journey на `probe_2k_activity_scan` — прогресс исчезает после завершения prepare
   (см. §7).
