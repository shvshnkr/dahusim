# Редизайн управления подписками (Library) — концепт

Ветка: `redesign`. Скоуп: только Compose/UI `LibraryScreen` + `LibraryGroupCard` + Add-шит;
бизнес-логика (GroupScreenViewModel, undoableRemove, updateAllSubscriptionGroups) не меняется.

## 1. Проблемы текущего экрана

| Проблема | Причина |
|---|---|
| Редкие сегменты (Manual/System) наравне с главным (Subscriptions) — 3 мелких chip | `LibrarySegmentRow` — FilterChip без иерархии и счётчиков |
| Карточка громоздкая: 3 контрола в ряд (Open / update / ⋮) + рамка OutlinedCard | `LibraryGroupCard` — каждый ряд = кнопки, действие «открыть» конкурирует с «обновить» |
| Нет визуального статуса подписки | Субтитр — только текст (трафик/срок), ошибка обновления никак не подсвечена |
| Обновить всё — иконка + confirm-диалог, прогресса по карточкам нет | Update-all спрятан в тулбар |
| Нет поиска и фильтра по ролям пула (WL/OPEN) — а это суть приложения | Список растёт с каждым сидом каталога |
| Добавление — трёхэтапно (FAB → шит → диалог/редактор) | `LibraryAddSheet` — 4 строки действий, контекст буфера обмена внизу |

## 2. Бенчмарк популярных клиентов (GitHub)

| Приложение | Паттерн | Что берём |
|---|---|---|
| **v2rayNG** | плоский список, update/delete иконками на карточке | Минимализм контролов |
| **Hiddify** | карточка подписки: usage-бар, бейдж истечения, статус-чип, tap→детали | Usage-бар + чип статуса на карточке |
| **Mihomo Party / Clash Meta** | карточки с usage-баром, датой истечения, мультивыбор, контекст-меню | Свайп-действия, состояние «обновляется» по всем карточкам |
| **NekoBox / SFM** | длинное нажатие → контекст-меню, активный профиль меткой | Long-press меню + метка активного |
| **ПроБел** | подписок нет — единая кнопка | — (нам нужен компромисс: простота + контроль) |

**Вывод:** карточка-«статус» вместо карточки-«панели кнопок»: tap → детали,
свайпы → быстрые действия, меню ⋮ → всё остальное. Фильтр по ролям WL/OPEN — уникальная
фишка под наш use-case (simple-mode работает на WL-пулах).

## 4. Карточка подписки

| Элемент | Что показывает | Состояния |
|---|---|---|
| Аватар (эмодзи/иконка из имени) | Быстрая идентификация | — |
| Имя + роль-чип `WL`/`OPEN`/`builtin` | Роль пула (суть приложения) | чип тонирован (WL — индиго, OPEN — зелёный) |
| Счётчик | `group_status_proxies` (N серверов) | 0 → «пусто» серым |
| Usage-бар | `subscription_traffic` (использовано/осталось) | нет данных → скрыт |
| Срок | `subscription_expire` | < 7 дней — оранжевый, просрочен — красный |
| Статус-чип | ok / updating (спиннер) / error / outdated N дн | цветовой код |
| Свайпы | слева-направо = Обновить, справа-налево = Удалить (undo-snackbar уже есть) | drag-ручка только в reorder-режиме |

Tap → детали (`LibraryGroupDetailChrome`, как сейчас). ⋮ → существующий options-шит
(share/QR/edit/delete). Long-press → тот же шит.

## 5. Действия

- **Обновить всё**: иконка в тулбаре превращается в спиннер, все карточки с
  `isUpdating` показывают прогресс-строку; confirm-диалог убрать (pull-to-refresh и так
  эквивалент). Ошибки — в snackbar + статус-чип на карточке.
- **Поиск**: поле в тулбаре фильтрует по имени/ссылке; Esc/крестик — сброс.
- **Фильтр ролей**: `[Все][WL][OPEN]` — фильтрует Subscriptions по `connectPoolRole`;
  при WL-фильтре подсветить строку «используется simple-режимом».
- **Сортировка**: по умолчанию порядок сегмента (reorder сохраняется); опции меню:
  имя / обновлено / alive-count — опционально (фаза 2).
- **Add-шит**: сохранить, но поднять clipboard-preview в карточку наверху шита
  (одним тапом импорт), остальные 3 строки — как сейчас.
