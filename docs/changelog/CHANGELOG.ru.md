# Changelog (RU)

Рабочая секция для следующего promote и pre-release. CI читает **`[Unreleased]`**; semver в заголовках не обязателен.

## [Unreleased]

### Добавлено
- Простой режим: переключение на запасной сервер с live-проверкой и выбором лучшего по задержке.
- Простой режим: приоритет личных подписок в автовыборе (наравне, приоритет, только личные).
- Простой режим: запасные серверы с отметкой «URL проверен» после успешной проверки.
- Простой режим: оранжевое уведомление после некорректной остановки VPN (H41).
- Канал обновлений: русские заметки из changelog и CLI `gh-workflow` для promote.

### Исправлено
- Автовыбор: стабильная сортировка пула — исправлен редкий сбой выбора при большом количестве серверов.
- Автовыбор: подписки с временными сетевыми ошибками (timeout/DNS/TLS) больше не уходят в бан — живые фиды остаются в пуле.
- Стабильность: исправлен редкий сбой определения владельца соединения (connection owner).
- Стабильность: ошибка первичной настройки больше не отключает фоновые обновления подписок.
- Простой режим (WL): перепроверка запасного сервера не блокируется недоступными через WL-uplink целями.
- Простой режим: зависания туннеля (stall) больше не откладываются бесконечно — жёсткий предел 90 с и переключение сервера после 3 успешных восстановлений за сессию.
