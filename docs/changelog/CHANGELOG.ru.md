# Changelog (RU)

Рабочая секция для следующего promote и pre-release. CI читает **`[Unreleased]`**; semver в заголовках не обязателен.

## [Unreleased]

### Добавлено
- Простой режим (BS): прогрессивный опрос серверов с конвейером — URL-проверка раунда идёт параллельно TCP-опросу следующего раунда, сеть не простаивает; адаптивный таймаут TCP (800 мс в 1-м раунде, 1200 мс дальше) — мёртвых не ждём.
- Простой режим: кандидаты с живой URL-проверкой (LKG, свежесть до 48 ч) проверяются первыми, до TCP-раундов — свежий живой сервер подключается без полного перебора (как на wl/BS, так и на открытой сети).
- Простой режим: ранний коннект по первому успешному URL — prepare завершается без полного ranking; очередь запасных = url-ok + tcp-alive. На wl/BS ранний выход после 1 url-ok объединённого пула; на открытой сети — после первых url-ok.
- Простой режим: при активном мессенджер-циркуте выбор раннего кандидата предпочитает url-ok с подтверждённым TCP — ложный url-ok (падает сразу после коннекта) не попадает в выбор.
- Каталог: добавлены 6 новых открытых фидов (исследование L2 strbypass/72378).
- Простой режим: обновлённый экран — проблемные состояния больше не выглядят «просто выключено»: при отсутствии интернета или отсутствии рабочих серверов показывается «Не удалось подключиться», во время переключений/нестабильности — пульсирующий статус «Переключение…» с пилюлей «Попытка N из M», постоянно виден трек шагов (Сеть → Подписки → Сервер → КВН) с подсветкой проблемного этапа.
- Уведомление: «Сменить» теперь переключает сервер одним тапом без открытия списка — выбор лучшего запасного по живой проверке (мёртвый резерв не выбирается); полный список по-прежнему открывается при включённой опции «Полный список серверов». При «уже лучший/нет резервов» соединение не рвётся, показывается только уведомление-тост.
- Ребрендинг: «VPN» → «КВН», «Husi» → «daHusiM» в интерфейсе.

### Исправлено
- Простой режим (BS): ранний коннект по первому url-ok теперь действительно завершает prepare — раньше коннект уходил в полный ranking и на БС добавлял десятки секунд к подключению.
- Простой режим: восстановление дозора серверов (revival watch) — мёртвый коннект при 0 живых URL на wl/BS больше не пробует заведомо мёртвые узлы.
- Простой режим: ручное переключение на запасной сервер учитывает недавнюю деградацию активного — после сбоя соединение не удерживается за проблемный узел, даже если резерв медленнее.
- Простой режим (BS): обновление подписок перед подключением больше не съедает бюджет — фоновый фетч получает явный таймаут, на БС-аплинке зеркало не дублируется прямым хостом (второй заход жёг полный таймаут на заблокированном L3); WL-свип пула не строит стратифицированный URL-пул и не ждёт мёртвые пробы после раннего выхода.
- Каталог: удалён неработающий фид wlrus-blackl.

## История promote
### Promoted 2026-08-17 · 1.2.0-alpha.33
 (744
) · run manual
### Добавлено
- Простой режим: переключение на запасной сервер с live-проверкой и выбором лучшего по задержке.
- Простой режим: приоритет личных подписок в автовыборе (наравне, приоритет, только личные).
- Простой режим: запасные серверы с отметкой «URL проверен» после успешной проверки.
- Простой режим: оранжевое уведомление после некорректной остановки VPN (H41).
- Канал обновлений: русские заметки из changelog и CLI `gh-workflow` для promote.
### Исправлено
- Автовыбор: стабильная сортировка пула — исправлен редкий сбой выбора при большом количестве серверов.
- Автовыбор: подписки с временными сетевыми ошибками (timeout/DNS/TLS) больше не уходят в бан — живые фиды остаются в пуле.
- Стабильность: исправлен редкий сбой определения владельца соединения (connection owner).
- Стабильность: ошибка первичной настройки больше не отключает фоновые обновления подписок.
- Простой режим (WL): перепроверка запасного сервера не блокируется недоступными через WL-uplink целями.
- Простой режим: зависания туннеля (stall) больше не откладываются бесконечно — жёсткий предел 90 с и переключение сервера после 3 успешных восстановлений за сессию.
- Простой режим: сервер, успешно прошедший проверку в текущем prepare, снова выбирается первым, даже если для него ещё не истёк старый период ожидания после сбоя — меньше «падений» на непроверенные узлы.
### Подписки
- Каталог: добавлены фиды КIЗЯК VPN — основной (open), BLACKLIST (wl) и TEST_RU (open).
